# v0.2 重构目标与验收

本轮目标：把“资料 → 理解 → 复习”做成可长期使用的中文个人学习工作台，修复可复现缺陷，完成验证后更新原 GitHub 仓库并发布新版本。

现状证据：旧界面从每份资料开头截断上下文，无法回答后半部分的问题；追问没有原始资料上下文；生成与追问共用全局临时状态，切换笔记本或连续按回车会产生竞态；localStorage 每次重绘同步写入，多标签页可相互覆盖；页面重绘会重建播放器；知识图谱和学习积分是预设演示。

## 验收范围

1. 中文工作台，完整资料导入、快速笔记、来源预览、笔记本创建/重命名/删除与资料关联；真实空状态和可选示例资料。
2. 针对整份资料分段检索，提供可检查的原文片段；摘要、概念图、记忆卡、播客基于选定资料生成，来源编号须通过服务端校验。追问绑定原输出资料，不能串到其他笔记本。
3. 真实记忆卡复习与下次复习日期、由生成概念构成的图谱；移除虚构积分、连续学习天数和预设图谱。
4. IndexedDB 保存工作区和音频；支持旧版数据与备份迁移、导入导出、多标签页冲突保护；损坏或存储失败不能静默丢弃/覆盖原数据。
5. 请求防重复、取消、切换上下文和删除期间的结果归属；播放器在其他操作时不重置。保留接口保护，增加结构化结果验证、上游取消和超时处理。
6. 自动化领域/API/真实浏览器测试，桌面与移动端视觉检查；更新文档、截图、迁移与限制说明；完成干净安装和发布包验证，推送 GitHub 并检查远程 CI，发布 v0.2 预发布版本。

真实供应商权限、计费和生成质量应与替代供应商测试分开记录。当前定位仍为个人/少量受信任用户的本地优先工具，不扩展为多租户 SaaS。
