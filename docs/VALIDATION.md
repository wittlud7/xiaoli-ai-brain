# v0.2 Beta 验证记录

验证日期：2026-10-22。环境：Windows、Node.js v24.12.0、npm 11.6.2、Playwright Chromium。

## 自动化覆盖

本机最终检查：41 项领域/API/存储/打包保护测试，以及 14 项真实 Chromium 流程测试全部通过；格式、语法和凭证特征扫描通过。截图为 1440px 桌面与 390px 手机宽度，未发现页面级横向溢出。

- API：本机绑定、访问口令、跨站/DNS 重绑定、限流、并发、请求边界、配置接口脱敏、上游错误脱敏、超时与取消。
- 学习：长文末尾检索、20 份来源覆盖、中文与字符边界、真实片段偏移、无效引用拒绝、结构化摘要/概念图/卡片/播客契约、带原文的追问。
- 存储：旧数据迁移、长历史保留、无效备份拒绝、串行写入、两连接版本冲突、失败不覆盖、音频重开/删除/脚本版本绑定、真实复习计划。
- 浏览器：中文空状态、笔记本与笔记操作、HTML 转义、四种输出与引用预览、概念掌握、复习进度、音频刷新恢复和播放器稳定性、备份恢复、切换笔记本期间结果归属、防重复追问、取消和删除、跨标签页同步、损坏数据恢复、模拟存储额度失败、PDF 实际提取、桌面/手机布局。

替代供应商在 fixtures/ 中，生产服务不会自动选择它。浏览器音频测试使用可解码的合成测试音频验证媒体行为，不代表真实 TTS 音质。

使用公开的牛顿第二定律短文，没有发送用户学习资料。只记录请求状态与结构校验，未记录密钥或上游原始错误内容。

## 可复现检查

```sh
npm ci
npm run check
npx playwright install chromium
npm run test:browser
npm audit --omit=dev
npm ci --prefix dist --omit=dev
node scripts/smoke-release.mjs
```

CI 配置 Windows/Linux × Node.js 22/24，并单独执行 Linux Chromium 浏览器测试。远程结果以 GitHub Actions 中对应提交的记录为准。

## 网页部署版本

`hosting/` 的 Worker 构建复用同一套网页与学习逻辑。单独执行：

```sh
npm run build:site
npm run test:site
npm run test:browser:site
```

Worker 契约检查覆盖静态资源、PDF 资源、登录身份、跨站拦截、四类生成、追问、请求大小、供应商错误脱敏和限流。部署包另有 4 项 Chromium 流程测试，覆盖导入、生成与引用、追问、复习、备份恢复、手机布局、登录过期、断线重连、额度错误和 PDF 实际解析。

浏览器检查通过仅监听本机的测试桥接运行实际部署包，身份与供应商响应为明确的测试替代物。它不会伪造真实用户的 ChatGPT 登录，也不证明真实供应商配额或云端登录会话始终可用。线上发布状态以 Sites 返回结果为准；未登录访问线上站点已确认显示平台登录页。

## 仍然存在的边界

没有做独立安全审计、生产负载测试、跨设备同步、OCR、各浏览器/屏幕阅读器的完整兼容性认证。检索是有界的词法检索，不保证同义词、图表或跨段知识全部召回；引用校验不是事实核查。
