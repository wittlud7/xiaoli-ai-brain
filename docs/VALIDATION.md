# v0.1 Alpha 本地验证记录

验证日期：2026-10-17。环境：Windows、Node.js v24.12.0、npm 11.6.2、Playwright 驱动的 Chromium。

## 已完成

- JavaScript 语法检查和待提交文件的常见凭证特征扫描。
- 15 项 Node 回归测试：本机绑定、共享口令、跨站请求、DNS 重绑定、HTTPS 来源、限流、并发、JSON/参数/请求体边界、缺少供应商配置、上游错误脱敏、静态资源边界、替代供应商契约、备份验证、存储失败、文本文件导入、语音分段。
- `npm audit --omit=dev`：在准备版本时报告 0 个已知漏洞；这不是持续的安全保证。
- 浏览器保存中文笔记、导入带文字层的单页 PDF，并确认提取的实际正文。
- 刷新后恢复资料、生成复习摘要、保留脚本并提示语音不可用、播客追问。
- JSON 工作区导出与确认后导入恢复。
- 1440px 桌面、390px 手机宽度截图检查；手机宽度无页面级横向溢出。
- 发布目录的依赖安装，以及发布服务器、首页、JavaScript 模块、PDF worker 的冒烟验证。确认 `.env` 和历史实现未打入运行包。

浏览器生成流程使用确定性替代供应商；语音失败场景由测试接口主动模拟。示例截图展示测试资料和测试生成结果，不代表真实模型效果。

## 尚未验证

- GitHub 远程 Actions 的 Windows/Linux、Node.js 22/24 矩阵；工作流已配置，推送后才会产生远程结果。
- 真实公网 HTTPS 代理、多用户负载、独立安全审计、屏幕阅读器与各浏览器的完整兼容性。

## 可复现的发布检查

```sh
npm ci
npm run check
npm audit --omit=dev
npm ci --prefix dist --omit=dev
node scripts/smoke-release.mjs
```

源码中的 `.env` 不进入发布目录，也不会用于上述替代供应商测试。不要将工作区备份作为测试附件提交到公开仓库。
